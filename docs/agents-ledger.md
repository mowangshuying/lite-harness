## 为什么搬出来（本轮实测）

- `AGENTS.md` 搬运前现值 **154,145** 码元，而注入预算 `AgentConst::kProjectInstructionsCharBudget
  = 16000`（`src/AgentConstants.h:455`），截断点在 `ProjectInstructions::formatSection` 的
  `text.left(budgetChars)`（`src/ProjectInstructions.h:82`）。
- 原 `## 构建` 节那条 CPack 条目**单行即 26,557 码元**，其第 582 码元之后全是逐批复测数字。
  于是注入窗口被打包历史整段吃掉，真正的规则（测试口径 / 架构 / 关键约定 / 发布授权 / 禁翻区）
  **一条都进不去**——`禁翻` 首次出现在 offset 81,093、`tr()` 在 74,852、`worktree` 在 43,565，
  全在窗口外。
- 这正是 `ProjectInstructions.h` 头注释自己登记的风险「截断静默吞尾：16000 字符后的规则凭空
  消失」在现仓的兑现形态。

## 新增登记的落点（纪律）

批次收口时的「××批复测 / 实跑登记 / 冒烟取证」写进**本文件末尾**，不再追加进 `AGENTS.md`——
每往 AGENTS.md 追加一次，就把它的规则往截断区外推一段，下一轮读注入内容的代理看到的更少。
`AGENTS.md` 里只留：当轮判据（现值）+ 指向本文件的一行指针。

判据口径不变：仍按「不改历史只登记」「归因一律逐修订 `git diff --numstat <rev>~..<rev>`」执行，
复算仍须 `git cat-file blob` 落原始字节再 `ReadAllLines`，不走 PowerShell 文本管道。
